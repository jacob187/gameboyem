# Test-ROM manifest and expected outcomes (the "ratchet").
#
# Format: <expect> <kind> <max_frames> <path relative to the roms dir>
#   expect: pass | fail      kind: blargg | blargg-mem | mooneye | acid2 | smoke | play-snake | play-breakout |
#         save-snake | save-breakout | sfx-snake | sfx-breakout | play-tobu | play-adjustris | play-renegade |
#         play-cgbdemo
#   A `-cgb` suffix on the kind (`mooneye-cgb`, `acid2-cgb`, `smoke-cgb`) runs the case on a Game Boy Color
#   (`Model::Cgb`); without it the case runs on a DMG. Only the suffix is special
#   (`blargg-mem` is its own kind). Comment lines start with `#`.
#
# Each line is one `cargo test -p gb-test --test roms` case. A case FAILS when
# the actual outcome differs from `expect` in either direction, so flipping a
# line from `fail` to `pass` is how a phase records progress, and regressions
# are caught. Paths may contain spaces (path is the rest of the line).
